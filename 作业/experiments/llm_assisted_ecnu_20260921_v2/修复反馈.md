## 8. 旧结果的有效性

仍然有效：固定样本清单、demo/holdout零重叠、真实 provider 可运行、逐case checkpoint、holdout只读，以及修复前真实调用/token的历史记录。

必须废弃或重算：旧约束违规率、旧 admitted/coverage 与 L2 regions、行级 bootstrap CI、旧 `search-only` 解释、被 proposal 覆盖后的 search best，以及包含 runtime 抖动和缺失 road 权重的旧 score、delta 与 regret。

## 9. 仍未解决的限制

1. 没有人工漂移标签、道路真值或独立 stationary validator。
2. 当前 objective 能评价简化相对去噪结果的几何表现，不能独立验证去噪删除正确性。
3. 每个分层只有2辆独立车辆、6条观测，分层差异只属探索性信号。
4. 不同 LLM 模式为独立请求，模式差异含模型生成波动。
5. 本轮没有扩大 demo，也没有验证 `min_samples=3/5` 的规模敏感性。
