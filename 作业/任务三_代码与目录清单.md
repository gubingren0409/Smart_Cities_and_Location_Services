## 2 源码目录

`traj_agent/` 目前包含 36 个 Python 文件。LLM 只负责提出工具调用和参数建议；几何、清洗、搜索、评分与记忆准入均由确定性代码执行。

### 2.1 core 确定性算法层

`core` 不依赖 `agent`、`tools`、`verifier`、`memory` 或 `report`，该约束由架构测试检查。

| 文件 | 主要职责 |
| --- | --- |
| [core/traj.py](traj_agent/core/traj.py) | 轨迹数据模型、JSON 载入、规范化和数据集统计 |
| [core/geo.py](traj_agent/core/geo.py) | Haversine、局部平面投影、距离、方向和路径长度 |
| [core/segment.py](traj_agent/core/segment.py) | 按车辆、时间间隔和空间跳跃执行分段与阈值扫描 |
| [core/anomalies.py](traj_agent/core/anomalies.py) | 非法坐标、重复点、时间异常、速度异常和漂移规则 |
| [core/clean.py](traj_agent/core/clean.py) | 将异常规则转换为清洗动作并保留原因账本 |
| [core/simplify.py](traj_agent/core/simplify.py) | Douglas–Peucker 简化、对照实现和容差扫描 |
| [core/metrics.py](traj_agent/core/metrics.py) | 点数、长度、Hausdorff、Fréchet、DTW 与运行时间指标 |
| [core/diagnosis.py](traj_agent/core/diagnosis.py) | 生成 LLM 可读取的诊断卡并划分轨迹状态与时间轴质量 |
| [core/params.py](traj_agent/core/params.py) | 参数默认值、合法区间、物理先验和数据驱动先验 |

## 7 结论口径

当前仓库能够证明：真实 `ecnu-plus` 已在固定 demo/holdout 上完成三轮修复版组件消融；raw/normalized/execution 参数可追踪；纯搜索参考不再被 proposal 覆盖；两个无 LLM 模式保持 0 次调用；最终 216 个唯一 case 全部成功；统计按 vehicle cluster 处理重复观测。

当前仓库不能证明：真实 LLM 稳定优于默认参数或有界搜索参考；Memory 已带来稳定质量收益；内部 objective 等价于道路真实质量。Memory paired effect 的车辆级 95% CI 覆盖 0，修复后 L2 没有满足 `min_samples=3` 的 region。`det-search-output` 的高内部得分仍需人工漂移标签或独立道路指标验证。
