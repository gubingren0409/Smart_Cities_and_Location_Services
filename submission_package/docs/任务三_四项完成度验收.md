## 二、真实路网验收

1. **道路数据是什么？** OpenStreetMap 的真实 `highway` way，使用 ODbL 1.0 数据；没有用 `roads_from_trajectory()` 生成的轨迹伪路网作为正式证据。

3. **共加载多少道路？** 12 个 case cache 合计 8,871 个 GeoJSON road features、8,969 个 matcher LineString parts；去重后涉及 7,814 个 OSM way id。跨 case 的空间重叠保留，汇总值不能解释为全上海唯一道路数。
4. **highway 类型分布？** 合计最多的是 `service=3101`、`residential=1553`、`primary=1244`、`tertiary=918`、`secondary=909`；完整分布在 `road_data_manifest.json`。
5. **真实 maxspeed 覆盖率？** 360/8,871 features，即 4.06%。处理后可比较速度点中，真实 `maxspeed` 占 7.38%，道路等级 fallback 占 92.62%。
6. **空间索引是什么？** Shapely `STRtree`；距离和吸附在 EPSG:32651（WGS84 / UTM 51N）中计算。
7. **12 条 holdout 是否全部完成？** 是，12/12；`road_eval_manifest.json` 中 missing=0、duplicate=0。
8. **road match 与距离？** 原始轨迹加权 match rate 72.05%，逐轨迹 median 距离均值 20.10 m、P95 均值 39.79 m；无路网处理结果加权 match rate 92.56%，median/P95 均值为 16.90/34.22 m。
9. **Road-aware 是否改变结果？** 是。336/363 个处理后点发生吸附；逐轨迹平均吸附位移均值 4.11 m，P95 均值 11.89 m，最大 29.61 m，退化轨迹为 0。
